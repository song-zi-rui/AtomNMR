快捷键说明

标注快捷键

Ctrl + S
保存当前修改，不结束任务
Ctrl + Enter
保存、结束并打开下一分子
Alt + ←
保存并返回上一分子
Alt + →
保存并打开下一分子
J / K
上一峰 / 下一峰；C 谱最后一峰再按 K，切到 H 谱第一峰
数字 + Enter
按图中编号切换原子选择，如 12 → Enter；再次输入同一编号取消
E
清空当前峰的全部归属，保留备注；等价组再次点击同一组可取消
C / H
切换碳谱 / 氢谱
Backspace
删除正在输入的原子编号
Esc
关闭当前峰编辑或本说明

输入框中的 E、数字、C / H、J / K 不触发全局快捷键；保存失败时不会跳转。Mac 可用 ⌘ 代替 Ctrl。
