# AtomNMR 文献归属提取

启动原 AtomNMR 标注系统后，从主页点击 **文献提取**，默认地址为 `http://127.0.0.1:8767/literature/`。**数据统计 → 文献提取** 汇总分子入库、谱级比对、归属峰数和批次记录。每个批次可返回控制台，查看论文原表和对应的主库记录。也可独立运行 `python -m literature_extractor.server --open`，在默认端口 8774 生成独立的批次数据库。

1. 选择论文根目录。每篇论文的正文 PDF、补充 PDF，以及可选的带编号 SDF 放进同一个直接子文件夹。只处理单篇时也可直接选存有该篇 PDF 的目录。
2. 散放的 PDF 可以先展开 **按论文整理散放的 PDF**，点击 **预览分组**。程序按 DOI、首页题名或文件主名称匹配。点击 **创建分组文件夹** 后移动 PDF。若目标组已有 SHA-256 一致的文件，程序清理根目录里的重复件。同名文件内容不同或匹配不确定时，会提示处理。
3. 设置 **目标分子数**，留空表示处理完当前队列。目标数统计本批已通过结构与编号检查并能写入 SQLite 的不同分子。遇到一篇论文有多个分子，先解析该篇，再严格按目标保存。余下分子在下个批次继续，已解析的 PDF 会复用缓存。带疑问或缺少编号结构的峰表进入报告。
4. 点击 **暂停** 后，当前文件夹解析结束就暂停。已经解析的内容保留。点击 **继续提取** 可接续本批。如果关闭过应用，用 **查看上次任务** 找回该目录的任务。换目录或改 PDF 名字也会复用相同内容的 PDF 解析结果。新增附件或 SDF 时只解析未缓存的 PDF。
5. 按化合物与核种查看实验峰表和原文。已确认编号的分子可在结构与峰表间双向查找。**下载本批 SQLite** 可取回该批提取并新增或补入归属的文献谱。主系统将批次报告和下载文件放在主库同一数据目录下的 `literature_extraction/<主库文件名>/batches/`。独立运行的结果位于 `outputs/literature_extraction/batches/`。

要在 AtomNMR 里打开此次生成的数据库，可以指定运行端口和数据库路径。

```powershell
python -m annotation_tool_v3.server --port 8773 --db "C:\路径\assignments.sqlite"
```

SQLite 保留实验来源、PDF 页码和表号、论文原子编号、峰范围及文献可互换组。AtomNMR 要求数值位移时使用区间中点，并在该行标明中点来源。每篇论文文件夹内只读取其直接包含的 PDF 和 SDF。

主系统入库前，按完整规范结构和核种查找主库候选。相同论文来源键会被识别；跨来源比对要求完整峰位及区间一致，已知条件相容，且有相同溶剂或相同论文来源。唯一对应的峰可补空白归属，已有标签、人工处理状态和可互换组发生冲突时保留待复核记录。不同实验谱按原结构归档；例如已有碳谱而本次找到独立的新氢谱，氢谱会加到同一分子下。位移取整、报告峰数不同或结构立体信息不同的记录可能需要另外核对。独立模式仍对照自身已导出的历史结果。

## 检索列表

展开 **检索论文**。分子英文名可以留空，或填 `Rapamycin` 这类名称。可勾选全合成、专门归属、归属修订、分离与结构鉴定。程序用 Crossref 与 Europe PMC 查公开元数据，按 DOI 去重。页面列出题名、期刊、年份、论文链接和筛选依据，可以下载 CSV。候选结果是否包含完整归属，应打开正文及补充材料确认。

同一检索也可以从终端运行。

```powershell
python -X utf8 -m literature_extractor.search --name Rapamycin --limit 6 --output outputs/rapamycin_literature.csv
```

## 支持的数据

当前流程**没有调用 LLM**。程序检查 PDF 文件，读取有文本层的表头、字符坐标、峰位和原文编号，保留区间和可互换组，再用 RDKit 对照已核对的结构或用户提供的 SDF。最后将能够映射的结果写入批次 SQLite。扫描 PDF、未知版式或结构图上尚未建立机器映射的论文需要复核。文件分组也通过规则完成。

程序已适配 Mauritines 论文正文的四张并列归属表，并内置该批次核对过的结构映射和实验条件。峰表每次从 PDF 读取。可供识别的其他文本 PDF 需要同页存在并列的 ¹H / ¹³C 位移列和各自的 `Assignment` 列，原子标签采用 `H12`、`H12′`、`C12` 一类的编号。没有结构映射、格式异常和扫描 PDF 会在结果报告中提示复核。

Lyngbyabellin O、P 补充材料中的天然样品与合成样品对照表也可以提取。程序按原子编号接续跨页表，数据库保存合成样品的峰位，天然样品和差值保留为原文对照。正文下载不完整时，文件列表会提示缺少 PDF 文件尾。若下载的是 HTML，页面会提示缺少 PDF 文件标头。

其他文献可在同一文件夹放入带原子映射的 SDF。将论文原子编号写入 SDF 的 atom map number，在该条结构的 SDF 属性中写 `PDF`（PDF 完整文件名）或 `DOI`（不带 `https://doi.org/`），以及 `Table`（例如 `1`、`S2` 或对照表的原文分子名）。推荐用 `PDF` 精确指定文件。H 标签引用结构里与氢相连的重原子编号。

运行环境沿用项目已有的 Python 3.11 或更新版本和 RDKit。PDF 使用 `pdfplumber`。本机可自动使用工作区的依赖运行时。其他机器可在启动环境安装 `pdfplumber`，也可以把装有它的 Python 路径写入 `ATOMNMR_PDF_PYTHON`。
